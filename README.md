# Pocket Signal

A tiny static website starter with a bold landing page and one lightweight interaction.

## Run

Open `index.html` directly in a browser.

## Files

- `index.html` - page structure
- `styles.css` - visual design
- `main.js` - small interactive signal demo
- `hello_chat.py` - tiny Python greeting script
- `short_reply.py` - another short Python back-and-forth script
